# qtfounder

量潮创始人项目。

## 结构

```
├── src/
│   ├── site/      → 创始人官网（React + Vite）
│   └── cli/       → CLI 工具（Rust）
├── .github/workflows/
└── README.md
```

| 目录 | 说明 | 开发命令 |
|------|------|---------|
| `src/site/` | 创始人官网 | `cd src/site && npm run dev` |
| `src/cli/` | CLI 工具 | `cd src/cli && cargo run` |
