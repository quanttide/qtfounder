# 页面规划

当前 Studio 已有首页入口与资产抽查模块（`lib/asset/`），尚无全局导航、路由和其余业务页面。下面的内容是已确认的方向，不是现有实现；实现进度见 [路线图](../ROADMAP.md)。

## 导航

导航栏按职能组织三个入口：资产、创作、思考。资产看「有什么」，创作做「怎么写」，思考看「状态如何」。导航栏是应用壳，内容区随职能切换，壳本身不重绘。

## 路由

规划使用 GoRouter，一级路由是 `/assets`、`/write`、`/think`；资产内部有 `/assets/fiction` 和 `/assets/memory`；阅读详情按文件路径进入。Web 端需要 SPA 回退。

## 资产

资产职能是聚合入口，内部按资产类型展开。小说页和记忆页都按目录结构展示，只读，不发明漏斗或统计视图。点击文件进入阅读页。

## 创作

写作页承载编辑器和改稿工作流。AI 只产出结构信息（分类、标签、摘要、拆分建议），不获得改写正文的通道；所有建议经用户确认才成为动作。审阅抽样可以在这里接入：抽出的文章进入编辑器，提交后回到批次。

## 思考

思考页把日志整理成事实、感受、需要、行动四类，结果可追加到日志，不改写原文叙事。数据源是 journal 日志。

## 审阅

审阅倾向放在创作流程里：从批次打开文章，编辑或确认无问题，记录标签和耗时。界面待重新设计后接入。

## 实施顺序

先恢复数据层和资产页，再做写作页，最后接思考和审阅界面。每一步都以当前代码为准更新文档；规划项实现后从本文件移走。
