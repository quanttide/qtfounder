# 页面规划

当前 Studio 已落地导航栏、数据标注（`lib/data/`）与资产抽查（`lib/asset/`）；写作、思考等其余页面待重建。下面未实现的内容是已确认的方向，不是现有实现；实现进度见 [路线图](../ROADMAP.md)。

## 导航

已实现：导航栏两个入口——数据、资产。资产看「有什么」，数据管记录与标注。导航栏是应用壳，内容区随职能切换，壳本身不重绘。

## 路由

已实现：命名路由 `/data` 与 `/assets`，内容区用 `IndexedStack` 切换，来回切不丢批次状态。Web 端需要 SPA 回退时再评估是否换 GoRouter。

## 资产

资产职能是聚合入口，内部按资产类型展开。小说页和记忆页都按目录结构展示，只读，不发明漏斗或统计视图。点击文件进入阅读页。

## 创作

写作页承载编辑器和改稿工作流。AI 只产出结构信息（分类、标签、摘要、拆分建议），不获得改写正文的通道；所有建议经用户确认才成为动作。审阅抽样可以在这里接入：抽出的文章进入编辑器，提交后回到批次。

## 思考

数据标注（`/data`，已实现）是这一步的第一小步：journal 段落贴「事实、感受、需要、行动」四类标签，结果落 `.annotations/journal.jsonl`。后续再做把整理结果可追加到日志、不改写原文叙事的页面。

## 审阅

审阅倾向放在创作流程里：从批次打开文章，编辑或确认无问题，记录标签和耗时。界面待重新设计后接入。

## 实施顺序

先恢复数据层和页面，再做写作页。每一步都以当前代码为准更新文档；规划项实现后从本文件移走。
