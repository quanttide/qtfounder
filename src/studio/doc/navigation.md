# Studio 导航栏设计

量潮创始人工作台（qtfounder_studio）的导航栏（应用壳侧边栏）设计。

## 定位

导航栏是工作台的**应用壳**——承载品牌识别与页面导航的常驻结构。内容区随导航切换，导航栏本身不随页面变化。

## 结构（三个职能）

导航栏按**职能**组织，无分组：

```
┌────────────┐
│     量潮    │  ← 品牌区
│            │
│  (资产)    │  ← 资产职能（聚合入口）
│  (创作)    │  ← 写作职能
│  (情绪)    │  ← 思考职能
│            │
│  (弹性区)  │  ← Spacer
└────────────┘
宽 80px · 白底
```

| 导航项 | 语义 | 图标（候选） |
| --- | --- | --- |
| 资产 | 资产聚合：记忆、小说等所有资产 | folder（或 widgets） |
| 创作 | 写作职能：写作/改稿工作流 | edit |
| 情绪 | 思考职能：情绪状态（cli 数据接入） | insights |

### 设计要点

- **资产是职能而非组**：资产页是**聚合入口**——记忆、小说等都是资产的一部分，进入资产职能后按资产类型展开
- 职能平级：资产（看全部资产）/ 创作（做创作）/ 情绪（看状态）——三个职能并列，无分组
- 资产可扩展：新资产（journal/report 等）加入资产职能内部，不改变导航栏结构
- 职能可扩展：新能力（如"分析"）作为新导航项加入

## 结构设计

| 区域 | 尺寸 | 内容 |
| --- | --- | --- |
| 品牌区 | 顶部 20px + 品牌字 | "量潮"（16px / w700 / 主色 4F46E5） |
| 导航项 | 40×40 圆角容器（10px） | 图标（20px，主色）+ 浅紫底（E0E7FF，选中） |
| 弹性区 | Spacer | 预留：底部导航项/版本信息 |
| 总宽 | **80px** | 图标优先的窄栏 |

## 设计决策

### 1. 为什么 80px 窄栏

- 工作台是**内容密集型**界面，导航应让位给内容
- 图标优先：导航项用图标表达，hover/选中态承载语义
- 窄栏 + 大内容区 = 生态内其他 Studio 一致的布局比例

### 2. 为什么资产是职能

- 资产（记忆/小说等）是**数据源集合**——聚合为一个职能入口，内部按资产类型导航
- 与创作（做）、情绪（状态）平级：三个职能回答三个问题——**有什么 / 怎么写 / 状态如何**
- 资产内部结构即仓库结构：不发明视图（见 [screens/fiction-asset.md](screens/fiction-asset.md)）

### 3. 选中态设计

- 选中项：浅紫底（E0E7FF）+ 主色图标
- 未选中：透明底 + 次级色图标
- 资产职能内选中态：进入子资产（小说/记忆）时，导航栏资产项保持选中（子页面不改变壳选中态）

### 4. 为什么圆角容器而非文字

- 80px 窄栏放不下中文导航名
- 圆角容器 + 图标 = 可扩展导航单元：加职能只需新增图标项

## 交互设计

| 交互 | 行为 |
| --- | --- |
| 点击导航项 | 切换内容区页面（壳内一级路由） |
| 选中态 | 浅紫底 + 主色图标（与品牌区同色系） |
| 内容区 | 随导航切换，导航栏自身不重绘（壳层稳定） |

## 演进方向

```
职能扩展：新能力（分析/规划等）→ 导航栏加项
资产扩展：新资产（journal/report/archive）→ 资产职能内部加子页
```

扩展规则：新增职能 = 导航项 + 一级路由；新增资产 = 资产职能内部子页 + 二级路由。导航栏结构（品牌区/导航项区/弹性区）不变。
