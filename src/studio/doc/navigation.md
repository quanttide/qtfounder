# Studio 导航栏设计

量潮创始人工作台（qtfounder_studio）的导航栏（应用壳侧边栏）设计。

## 定位

导航栏是工作台的**应用壳**——承载品牌识别与页面导航的常驻结构。内容区随导航切换，导航栏本身不随页面变化。

## 结构设计

```
┌────────────┐
│     量      │  ← 品牌区（20px 顶部留白 + 品牌字）
│            │
│  (图标)    │  ← 导航项区（40px 圆角容器 + 图标）
│            │
│            │
│  (空白)    │  ← 弹性区（Spacer，把底部推向底部）
│            │
└────────────┘
宽 80px · 白底
```

| 区域 | 尺寸 | 内容 |
| --- | --- | --- |
| 品牌区 | 顶部 20px + 品牌字 | "量"（20px / w700 / 主色 4F46E5） |
| 导航项区 | 40×40 圆角容器（10px） | 图标（auto_stories，20px，主色）+ 浅紫底（E0E7FF） |
| 弹性区 | Spacer | 预留：底部导航项/版本信息 |
| 总宽 | **80px** | 图标优先的窄栏 |

## 设计决策

### 1. 为什么 80px 窄栏

- 工作台是**内容密集型**界面（创作现场三视图），导航应让位给内容
- 图标优先：导航项用图标表达（auto_stories=创作），hover/选中态承载语义
- 窄栏 + 大内容区 = 生态内其他 Studio（qtdata/econ/delib）一致的布局比例

### 2. 品牌区为什么是"量"

- 单字品牌（"量"）是量潮全系 Studio 的统一标识（qtdata/econ 同款）
- 20px / w700 / 主色——与导航项图标视觉同层，不喧宾夺主

### 3. 选中态设计

- 当前实现：单一导航项，选中态 = 浅紫底（E0E7FF）+ 主色图标（与品牌区呼应）
- 语义：选中项 = "当前在创作现场"——用颜色深浅区分"选中 vs 未选中"

### 4. 为什么导航项用圆角容器而非文字

- 80px 窄栏放不下文字（中文导航名至少 4 字 = 60px+）
- 圆角容器（10px）+ 图标 = 可扩展的导航单元：未来加页面只需新增图标项
- 图标语义映射（当前）：`auto_stories` = 创作现场

## 交互设计

| 交互 | 行为 |
| --- | --- |
| 点击导航项 | 切换内容区页面（当前单页，未来多页） |
| 选中态 | 浅紫底 + 主色图标（与品牌区同色系，视觉归属一致） |
| 内容区 | 随导航切换，导航栏自身不重绘（壳层稳定） |

## 演进方向

当前只有一个导航项（创作现场），导航栏是**预留扩展**的结构：

```
未来导航项候选：
├── 创作现场（auto_stories）      ← 当前
├── 章节详情（menu_book）         ← ROADMAP 目标 2
├── 情绪状态（insights）          ← cli 数据接入
└── 设置（settings）              ← 数据源配置可视化
```

扩展规则：新增页面 = 新增一个图标导航项 + 内容区切换逻辑；导航栏结构（品牌区/导航项区/弹性区）不变。
