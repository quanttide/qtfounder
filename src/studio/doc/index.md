# Studio 文档

本目录描述当前代码、当前边界和已确认的下一步。归档业务层的详细设计不再作为当前实现文档；需要历史设计时查 Git 历史或归档代码。

## 定位

Studio 的定位是创作现场的观察层：让创作过程可见。导航栏按职能组织入口；当前已落地两个模块（标注规则设计、资产抽查），其余页面待重建。

## 当前形态

`lib/main.dart` 是应用壳：左侧导航栏（`数据`、`资产` 两个入口）加命名路由 `/data`、`/assets`，内容区用 `IndexedStack` 切换。`lib/data/` 是标注规则设计模块（规则列表、编辑器、试标、任务包导出），`lib/asset/` 是资产抽查模块（扫描、批次卡片流、保留/删除）。数据契约在 `assets/contracts/`，运行时尚未接入。

## 阅读顺序

新加入的人先读根目录 [README](../README.md)，再读架构；要恢复业务层时读数据源与页面规划。`planned-ui.md` 里的内容都是规划，不是当前实现。

## 维护规则

文档跟着代码走：新增能力时更新对应文档，能力未实现时标为规划，不把归档代码的设计写成当前实现。子模块文档不链接父仓文件，跨仓库历史只写路径文本。
