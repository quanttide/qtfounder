# 创作职能页设计（/create）

量潮创始人工作台的创作职能页——**创作活动的唯一承载**（写作/编辑/改稿/规划落地只在此页，资产页只读）。

## 定位

资产页回答"有什么"，创作页回答"怎么写"。创作职能把**想写的东西**变成**写好的东西**：沿 fiction 的四阶段工作流（灵感 → 脚本 → 初稿 → 改稿）推进创作。

## 创作流模型（数据源：fiction 四阶段）

```
1_灵感（思想/情绪源头）→ 2_脚本（场景素材）→ 3_初稿（成文未定稿）→ 4_改稿（定稿章节）
```

- 素材池 = 2_脚本（有编号=已定位，无编号=未排序）
- 产出 = 3_初稿 / 4_改稿（编号即排序，版本后缀即迭代）
- 当前焦点 = roadmap/fiction.md 的 11_x 世界扩张（规划 → 脚本 → 初稿 → 改稿）

## 页面结构

```
创作
├── 当前焦点：11_x 世界扩张
│     （规划中 → 脚本 → 初稿 → 改稿——四阶段进度）
├── 素材池（2_脚本）
│     ├── 已定位：2_2_男主演讲、9_1_包子店…
│     └── 未排序：偷看睡觉、再坐便利店…
└── 方法速查（context/fiction-adaptation.md）
      场景先行 → 物证化 → 减法优先 → 独白→问答 → 动作外化 → 具象落点
```

## 功能设计（最小闭环）

### 1. 当前焦点

- 展示创作目标（来自 roadmap/fiction.md）：11_x 世界扩张三层（聚光灯下/包子店/再坐便利店）
- 阶段进度：目标 → 素材 → 初稿 → 改稿（真实文件是否存在的状态）

### 2. 素材池

- 列出来自 2_脚本 的素材（复用资产目录引擎——fiction 契约的 stage=2_脚本）
- 素材状态：已定位（有编号）/ 未排序（无编号）
- 点击素材 → 查看内容（只读阅读，同资产页）

### 3. 方法速查

- 转化规律 8 条（context/fiction-adaptation.md 的内容速览）
- 创作时对照：写正文时按规律加工素材

### 4. 写作入口（核心）

- 选择素材（或焦点章节）→ **打开写作视图**
- 写作视图：素材内容 + 转化方法提示 + 正文编辑区
- 保存：生成/更新 fiction 中的文件（初稿或改稿）——**创作页唯一允许的写操作**

## 边界

| 动作 | 归属 |
| --- | --- |
| 浏览素材/阅读 | ✅ 本页可引用（阅读视图） |
| **写作/编辑/保存章节** | ✅ **本页**（唯一写操作点） |
| 浏览资产结构 | ❌ /assets（本页只引用内容，不做目录浏览） |
| 情绪观察 | ❌ /emotion |

## 设计要点

1. **创作流即页面**：四阶段进度 = 真实文件状态（不发明状态字段）
2. **素材→正文转化**：方法速查内嵌在写作视图——创作时即查即用（对齐转化 8 条规律）
3. **只读与写分离**：阅读复用资产页模式；写操作集中在本页（编辑区）
4. **最小闭环**：焦点 → 素材 → 写作 → 保存——不做规划外的抽象

## 数据流

```
roadmap/fiction.md（焦点）──→ 当前焦点
fiction/2_脚本（素材）──────→ 素材池（复用资产目录引擎）
context/fiction-adaptation.md → 方法速查
写作视图 ──保存──→ fiction/3_初稿 或 4_改稿（写文件）
```

## 演进顺序

1. 当前焦点 + 素材池（复用引擎，只读展示）
2. 方法速查（静态展示）
3. 写作视图（素材 → 正文编辑 → 保存为初稿/改稿）
4. 阶段推进联动（保存后焦点进度更新）
