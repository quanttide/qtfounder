# 创作职能页设计（/create）

量潮创始人工作台的创作职能页——**在 fiction 结构上工作的视图**（资产页只读，本页可写）。

## 定位

与资产页同一结构（小说 → 阶段 → 文件），区别只有一个：**可写**——新建文件、编辑文件。

```
资产页（/assets/fiction）   创作页（/create）
同结构 · 只读              同结构 · 可写
"看"                      "做"
```

## 页面结构（= 仓库结构）

```
创作
├── 职场言情
│   ├── 1_灵感/     [+ 新建]
│   ├── 2_脚本/     [+ 新建]
│   ├── 3_初稿/     [+ 新建]
│   └── 4_改稿/     [+ 新建]
│       每个文件：点击 → 写作视图（编辑）
├── 校园言情 …
└── 重生言情 …
```

复用资产目录引擎（同一棵树），节点和文件上增加操作。

## 功能

| 操作 | 行为 |
| --- | --- |
| 阶段上「新建」 | 在该阶段创建新文件（命名按阶段习惯：编号或自由名） |
| 文件点击 | 打开写作视图（编辑该文件） |
| 写作视图 | 正文编辑区 + 保存（写回文件） |

## 边界

- 本页唯一可写：新建/编辑 fiction 文件
- 浏览结构只读部分复用资产页逻辑（引擎同源）
- 不做其他职能的事（情绪/记忆浏览）
