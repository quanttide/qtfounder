# ROADMAP

量潮创始人官网（qtfounder-site）。

## 目标

实现 `docs/index.md` 的设计：从"作品集"到"创作现场"。核心问题：**这个人正在创造什么？**

版本：site/v0.1.0（结构类变更：页面重构、数据模型扩展）。

## 当前状态

- 首页：Hero + 关于 + 最近 3 篇作品
- 作品页：`全部 / 改稿` 筛选
- 详情页：单版本全文展示（`src/content/works/fiction/*.md`）
- 数据：`data/works.ts` 静态清单（type 仅 `改稿`）

---

## 阶段 1：数据层扩展

| 任务 | 说明 |
|------|------|
| 扩展 `works.ts` | type 扩展为 `改稿 / 文章 / 游戏 / 工具`；新增 `revisions` 字段（v0 初稿 / v1 叙事调整 / v2 语言润色，日期 + 一句话说明） |
| 新增 `data/streams.ts` | 四个创作域（小说/游戏/工具/思考）的活状态：当前状态 + 最近动态 + 下一步 |
| 新增 `data/activities.ts` | 创作流静态数据：日记摘录、小说更新、游戏里程碑、文章，按时间倒序 |

## 阶段 2：首页改造

| 任务 | 说明 |
|------|------|
| Hero 实时锚点 | 当日创作动态摘要（静态版：手填今日数据） |
| 创作流时间线 | 首页核心区块，混合类型按时间倒序，最多 10 条，附"更多 →"链接到 `/works` |
| 创作域矩阵 | 四个创作域各占一格，展示活状态而非静态卡片 |
| 联系区块 | GitHub / 邮件 / 社交链接，无表单 |

## 阶段 3：作品页扩展

| 任务 | 说明 |
|------|------|
| 筛选扩展 | `全部 / 改稿 / 文章 / 游戏 / 工具`，文字链接，选中加粗 |
| 类型标签 | 灰色文字，无背景/边框/badge（保持现状） |

## 阶段 4：改稿轨迹（过程即作品）

| 任务 | 说明 |
|------|------|
| 内容按版本组织 | `content/works/fiction/<slug>/` 目录存放多版本，或 frontmatter 标注版本 |
| 详情页轨迹展示 | 初稿 → 改稿轨迹列表（版本 + 日期 + 说明），可切换查看各版本正文 |
| 其他类型详情 | 暂不设计，链接到外部原文或仓库 |

## 阶段 5：数据自动化（后期）

| 任务 | 说明 |
|------|------|
| 构建脚本 | 从子模块 git commit 生成活动流 JSON（journal 摘录、小说更新、游戏版本），避免手工维护 |
| 静态清单互补 | `data/works.ts` 保留为静态作品清单，与活动流互补 |

---

## 验收与发布

- 每阶段完成后运行 `npm run build` 验证
- 全部完成后打 `site/v0.1.0` tag 并更新 `src/site/CHANGELOG.md`

## 风格约束

- 维持克制 / 文字优先 / 留白原则（见 `docs/index.md`）
- 颜色仅黑、白、灰；无动画、无渐变、无卡片阴影
